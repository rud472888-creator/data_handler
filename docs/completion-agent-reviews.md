# 완료 후 에이전트 검토

Data Handler 작업 공간에서 카드를 선택하면 오른쪽 **에이전트 검토**에 복제 검토, 보고서 검토, 촬영 기록 대조가 표시된다. 각 항목의 바로가기로 이동하고, 확인할 근거·가능한 원인·추천 행동을 펼치거나 전체 JSON 기록을 내려받을 수 있다. **다시 검토**는 매번 새 세션으로 실행한다.

## 기존 경로와의 연결

- `agent/reviews.py`의 완료 수집기는 DIT 앱과 기존 로컬 에이전트 서비스의 수명 주기에 연결된다. 두 프로세스가 함께 실행돼도 단계별 파일 잠금과 입력 리비전으로 중복 실행을 막는다.
- `events/datamanager.done.json` 이후 기존 `blackmagician/manifest.json` 및 `blackmagician.review.file_evidence`를 재사용한다. 원본·복제 체크섬, 파일별 작업 식별자, 파일 수, 승인된 모든 목적지, 현재 복제본 존재·크기를 확인한다. 중복 파일 식별자, 같은 목적지를 가리키는 파일, 다른 작업의 manifest를 정상으로 처리하지 않는다.
- `events/datahelper.done.json` 이후 PDF와 함께 생성한 JSON의 요약, 클립, 프레임, 오류, 경고를 읽는다. 종료 코드 0도 내용 검토를 통과해야 한다. 복제본별 보고서 누락, 입력 카드 불일치, 누락된 단일 파일 클립, 디코딩·메타데이터·SDK·권한 오류를 분리해 원인 후보와 후속 행동을 제공한다.
- DataHelper worker는 완료 이벤트를 내기 전에 `agent/report-inputs/pathN.json`에 해당 카드의 보고서 사본을 저장한다. 다음 카드가 프로젝트 공용 보고서를 덮어써도 검토 근거가 바뀌지 않는다. 도구 실행 예외도 실패 완료 기록으로 남긴다.
- Blackmagician 연결 상태와 저장된 스냅샷은 기존 `public_state` 경로에서 가져오며 기존 `build_review`로 파일별 대조를 수행한다. 이번 백업의 파일명과 촬영일·카메라를 기준으로 `shootDayKey/cameraId/reel` 범위를 유일하게 정할 수 있을 때 해당 릴의 전체 기록을 대조한다. 로컬 `R#n`을 카메라 릴 번호로 간주하지 않는다. 중복 이름, 불완전한 범위, 상충 기록, 오래되거나 불완전한 스냅샷은 확인 필요로 남긴다. 완료 후 생성된 촬영 기록은 제외한다.

원본 `DataManager`와 `DataHelper` 소스는 이번 구현에서 변경하지 않았다. 래퍼와 기존 연동 모듈을 확장했다.

## 세션과 복구

각 단계·각 재시도는 무작위 UUID 세션을 만든다.

```text
.pipeline/runs/<run_id>/agent/
  report-inputs/pathN.json
  reviews/
    copy.json
    report.json
    shooting.json
    <phase>.lock
    <phase>.retry.json
    sessions/<새 UUID>/
      request.json
      evidence.json
      result.json
```

`request.json`의 대화 이력은 항상 비어 있다. 로컬 추론 서버의 별도 `POST /review`는 `session_id`, `phase`, `evidence`만 허용하고 `history` 등 추가 필드는 거부한다. 생성에는 고정 검토 지침과 이번 근거만 전달하며, 이전 결과·대화·도구·프롬프트 캐시를 전달하지 않는다. 모델 가중치는 재사용할 수 있지만 검토 컨텍스트는 재사용하지 않는다. 복제 계획 수정을 위한 기존 대화 UI의 이력과 완료 검토는 별개다.

전체 파일 검토는 결정적 코드가 수행한다. 모델에 넘기는 오류 목록만 크기 제한을 적용하며 생략 개수를 함께 보낸다. 모델 응답은 **에이전트 의견**으로 표시하고 검증 상태를 바꿀 수 없다. 응답 세션 ID가 다르면 거부한다.

모델이 없거나 응답에 실패하면 파일 근거 검토를 보존하고 그 사유를 표시한다. 다시 검토하면 새 세션에서 재시도한다. 중간 종료된 세션은 수집기 재시작 시 새 세션으로 복구한다. 수집기는 완료 파일만 읽으며 복사 엔진의 실시간 진행률을 관찰하지 않는다. 앱이나 에이전트가 꺼져 있던 동안의 완료 기록도 재시작 후 처리한다.

Blackmagician을 나중에 연결하거나 스냅샷을 다시 동기화한 경우 **다시 검토**로 새 근거를 반영한다. 완료 결과가 이후 촬영 기록에 따라 자동으로 바뀌지는 않는다.

## 해석 범위

- 체크섬은 복제 완료 당시 기록을 재검토한다. 현재 파일 존재·크기를 확인하지만 전체 바이트를 다시 해시하거나 원본 카드를 다시 스캔하지 않는다.
- 보고서 검토는 구조화된 검수 결과를 읽는다. 영상 전체를 재생하거나 PDF의 모든 화면을 시각 검수하는 기능은 아니다. 분할 RAW의 물리 파일 수와 논리 클립 수는 일대일로 비교하지 않는다.
- 촬영 기록에 없는 파일, 물리 카드 UUID, 정확한 녹화 시작 시각은 추측하지 않는다. 릴 번호 재사용과 기록 생성 시각의 한계는 결과에 표시한다.
- 새 경고는 작업 공간 카드 상태에 반영되며 기존 엔진 체크섬 완료 사실은 별도로 유지된다. 자동 재복제·삭제·원격 촬영 기록 수정은 실행하지 않는다.
